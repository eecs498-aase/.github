# Applied Agentic Software Engineering

We write it **AASE** and say it "A two S E."

A 4-credit University of Michigan course on building software with AI coding agents: learn the tools, script your own agents, then design and ship a production-grade agent orchestrator.

## The three phases

| Phase | Weeks | Weight | Focus | You ship |
|-------|-------|--------|-------|----------|
| **01** AI-Assisted Development | 1–3 | 20% | Aider, then Claude Code. The Big Three: context, model, prompt. | A real Python app, built with both tools |
| **02** Scripted Agentic Workflows | 4–6 | 25% | Direct LLM API calls, tool use, the agent loop, Claude Code customization, MCP | A focused agent with an eval suite |
| **03** Agent Orchestrator Capstone | 7–15 | 55% | State, multi-agent patterns, MCP, observability, cost, deployment | A deployable orchestrator, demoed live |

**No exams.** Projects, lab checkoffs, and live demos. All projects are individual.
